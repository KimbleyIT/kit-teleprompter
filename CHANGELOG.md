# Changelog

All notable changes to the Kimbley IT Teleprompter are recorded here,
newest first. Every change pushed to this repo gets an entry.

This is a single-file HTML app (index.html) with no build or deploy
step — whatever is on main IS the released version.

## 2026-04-06

### Added
- Initial release: single-file HTML teleprompter for recording YouTube
  videos — auto-formatted scripts, adjustable speed and font size,
  colour modes, mirror mode, light/dark theme, text alignment,
  draggable reading bar, and full screen support. No dependencies.

### Changed
- Renamed teleprompter.html to index.html.
- Speed boost tuned when crossing gaps between paragraphs.
